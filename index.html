Minnesota Government Data Practices Act (MGDPA) Guide

Door-to-door solicitor registration and peddler permits are governed under Minnesota Statute Chapter 13 (MGDPA). Here is how data collection works for local software developers:

Public Data (Scrapable / Requestable)

  • Company / Employer Name and Address
  • Solicitor / Sales Rep Name (Issued Badge Name)
  • Permit Number, Issue Date, and Expiration Date
  • Approved Products/Services Description
  • Approved door-to-door operation area or dates

Private Data (Redacted by Cities)

  • Applicant Drivers License / State ID Number
  • Personal Home Address, Phone Number, and Personal Email
  • Background Check Results / Criminal Records
  • Social Security Numbers
Requesting Non-Published City Records

If a suburb (e.g., Maple Grove, Plymouth, Eagan) does not publish a live PDF or web directory, you can submit an automated MGDPA public data request to the City Clerk or Police Records division requesting the "Active Commercial Solicitor & Peddler License Roster".
